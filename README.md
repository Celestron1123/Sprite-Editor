# Sprite-Editor

**Sprite-Editor** is a lightweight application built with C++ and Qt, designed for creating and animating pixel art.  
It provides an intuitive interface for artists and developers to design sprites frame-by-frame, supporting essential features for pixel art animation workflows.

## Features

- **Frame-by-Frame Animation**: Create animations by adding, drawing, and editing individual frames.
- **Pixel-Level Editing**: Utilize a pixel-precise canvas for detailed sprite creation.
- **Customizable Canvas Sizes**: Select from various canvas dimensions to suit different project needs.
- **Real-Time Preview**: Instantly preview animations to assess motion and timing.
- **User-Friendly Interface**: Navigate through a clean and responsive UI tailored for efficiency.

## Installation

### Prerequisites

- **Qt Framework**: Version 5.x or higher.
- **C++ Compiler**: Supporting C++11 standard or higher.

### Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Celestron1123/Sprite-Editor.git
   ```

2. **Navigate to the Project Directory**:
   ```bash
   cd Sprite-Editor
   ```

3. **Open the Project in Qt Creator**:
   - Launch Qt Creator.
   - Open the `SpriteEditor.pro` file located in the project directory.

4. **Build and Run**:
   - Configure the project using the appropriate kit for your system.
   - Build the project.
   - Run the application within Qt Creator.

## Usage

Upon launching the application:

- **Create a New Sprite**: Define the canvas size and start drawing using the pixel editor.
- **Add Frames**: Build animations by adding new frames and editing them individually.
- **Preview Animation**: Use the preview feature to play the animation and make adjustments as needed.
- **Save Your Work**: Export your sprite or animation for use in games or other projects.

## Project Structure

- `main.cpp`: Entry point of the application.
- `mainwindow.*`: Defines the main window and its functionalities.
- `frame.*`: Manages individual animation frames.
- `sprite.*`: Handles the collection of frames as a complete sprite.
- `pixel.*`: Manages pixel-level data and interactions.
- `sizeselector.*`: Implements the dialog for selecting canvas size.
- `help.*`: Contains the help dialog and related information.
- `ArtGallery/`: Directory for storing example sprites and user creations.
